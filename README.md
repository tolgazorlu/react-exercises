# React Exercises

Small Node.js exercises practicing async data fetching, created as groundwork for React projects.

## About
A practice repo created in October 2022. The current exercise fetches user data from a public API with axios and logs it to the console; it does not use React itself yet.

## Features
- Async/await data fetching with axios
- Fetches sample user data from `jsonplaceholder.typicode.com`

## Tech stack
- Node.js, axios

## Getting started
```bash
npm install
npm start
```

## Status
Learning project, not maintained.
